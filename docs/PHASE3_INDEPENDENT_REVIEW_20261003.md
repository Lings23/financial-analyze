## 待执行的评审

评审应来自未参与本轮实现或生成答案的人员/独立标准，先确认研究问题和要求，再查看输出，依据原scope、证券、报告期、口径、cutoff、版本及来源原文判定。不要仅凭本系统的verified标记或另一段模型回答评分。

1. 对数值Claim检查原始值、单位、期间、计算、来源与时间。官方现金流25项、既有财报参考、Fraction重算各自证明的范围有限；没有独立参考的部分注明not_assessable及原因。
2. 对每个假设检查事实是否支持该状态、反证是否完整、结论强度是否越过描述性检验。不能把“同向”“发生在披露后”解释成因果。
3. 对事件检查指定记录、身份、版本、披露精度及前后价的时间可行性。明确报告event_anchor缺失本身不等于已完成该研究任务。
4. 阅读完整Markdown，记录未列出的主张、漏报与歧义；新增主张须补入新冻结评审清单，当前评分器不会将其静默排除。
5. 按整个请求判断Task Success，而非JSON格式、候选选择或单个数值正确。填明评审者、时间、独立性说明和所有判断的证据位置。当前材料不是预先隔离的独立盲样，完成本表也不能直接认证广泛Phase3质量。

目标保持PLAN的L3/L5分别≥85%、ESR≥98%、Hallucination≤1%、关键锚点100%。不确定支持计入支持率分母，待判断时不计算幻觉率；缺失必需项保留失败。已知必需检验未完成的任务不能被人工表格中的一个true覆盖。
