## 实际发现并隔离的解析风险

第二版候选解析使用过宽的后续行检索，在中草香料半年报PDF第37页可能把营业总成本当营业收入；这批`layout2/candidates.json`保留且**没有计分或入金融快照**。

第三版只接受同页数值续行或利润标签续行，遇到另一行费用/收入即停止。该版本不自动处理“数值排在标签上一行”的表格。此前已核对的茶花半年报归母净利润标签跨PDF第35/36页，补查实际续行后保留其原资格；其他重合字段数值/单位/页码一致。旧142比较结果仍可重算。

另手工读取两种不宜自动猜列的格式：

- 中草香料半年报第37页，营业总收入和营业收入各有独立印刷行，均101,752,495.08元；渲染原页核对标签与数值实际对齐，未使用错误候选的95,407,883.86元费用行。
- 瑞丰银行半年报第74/75页是“合并及银行利润表”，含本集团、本行及两个年份。核对本集团2025列：营业收入2,258,607千元，归属于本行股东净利润889,637千元。来源语义对应合并累计母公司股东归属，而非合并净利润总额。

总计目视检查九个代表页，不声称全部PDF页人工目视审查；其余依据明确表头/期间/单位/行与哈希的机器辅助审核。独立数值文件固定后才读取对应Tushare数值，未按是否匹配选择参考。
