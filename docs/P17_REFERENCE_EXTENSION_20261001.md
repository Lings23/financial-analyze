## 时间差异与权限

920118 的 CNINFO 官方索引日期为 2025-04-25（年报/一季报）和 2025-08-27（半年报）；原 Tushare ann_date 为 2025-04-26 和 2025-08-28。保留两套来源日期，未以任一日期倒填 available_at。索引时间是当地零点，无法判断首次日内公开时刻。

Tushare `anns_d` 的[官方文档](https://tushare.pro/document/2?doc_id=176)定义 `rec_time` 为发布时间且需要单独权限。本账号实际调用返回 **40203 权限不足**；封存业务码和请求字段，没有把失败当成成功空表。历史版本公开时间仍未验证，真实记录继续采用 observed_at。
